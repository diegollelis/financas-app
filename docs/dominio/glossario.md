# Glossário

## Termos da interface (pt-BR ↔ código)

O nome que a pessoa vê na tela e o nome no código são independentes ([ADR 0051](../adr/0051-vocabulario-da-interface.md)). Esta tabela é a ponte entre os dois. Um termo novo da interface entra aqui primeiro, e um conceito tem um nome só em todas as telas, nos toasts e nos e-mails.

### Espaços e acesso

| Interface                          | Código                        | Definição                                                                   |
| ---------------------------------- | ----------------------------- | --------------------------------------------------------------------------- |
| Espaço                             | `Workspace`                   | Conjunto de dados financeiros, de uma pessoa ou compartilhado               |
| Pessoal                            | `isPersonal`                  | O espaço de cada um, criado no cadastro; nunca é compartilhado nem excluído |
| Membro                             | `Member`                      | Vínculo de uma conta com um espaço, com um acesso                           |
| Dono / Pode editar / Só visualizar | `OWNER` / `EDITOR` / `VIEWER` | O acesso do membro (`roleLabels` em `packages/shared`)                      |
| Convite                            | `Invitation`                  | Link enviado por e-mail para entrar num espaço                              |

### Lançamentos

| Interface                                  | Código                                                          | Definição                                                                                                                                                                                                                                                                |
| ------------------------------------------ | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Lançamento                                 | `Transaction`                                                   | Uma entrada ou uma saída de dinheiro                                                                                                                                                                                                                                     |
| Entrada / Saída                            | `CREDIT` / `DEBIT`                                              | O tipo do lançamento                                                                                                                                                                                                                                                     |
| Categoria                                  | `Category`                                                      | Classificação do lançamento, de um tipo só                                                                                                                                                                                                                               |
| Mês (na importação, Mês de referência)     | `period` (`YYYY-MM`)                                            | O mês ao qual o lançamento pertence (nos docs técnicos, "competência")                                                                                                                                                                                                   |
| Data da compra / Data                      | `occurredOn`                                                    | O dia em que a compra (saída) ou a entrada aconteceu; não muda o mês de referência ([ADR 0055](../adr/0055-importacao-da-fatura-do-cartao.md))                                                                                                                           |
| Vencimento                                 | `dueDate`                                                       | Data prevista para pagar ou receber                                                                                                                                                                                                                                      |
| Vence no: Mesmo mês / Mês seguinte         | `dueMonthOffset` (0 / 1)                                        | Numa recorrência ou num parcelamento, em que mês cada um vence, contado do seu próprio mês                                                                                                                                                                               |
| Pago em / Recebido em                      | `settledAt`                                                     | Data em que a saída foi paga ou a entrada foi recebida                                                                                                                                                                                                                   |
| Marcar como pago / recebido                | `PATCH { settledAt }`                                           | A ação de registrar o pagamento ou o recebimento                                                                                                                                                                                                                         |
| Pagar / Receber                            | `settleActionLabels[type].short`                                | O botão da linha que marca como pago ou recebido (o nome completo fica no menu)                                                                                                                                                                                          |
| Recebimento parcial / Pagamento parcial    | `POST …/settle-part`, `SettlePartDialog`                        | Lança, já quitada, só uma parte de um lançamento pendente, no mês da data; o pendente fica com o resto e sai da lista quando zera ([ADR 0057](../adr/0057-receber-parte-e-a-receber-sem-data.md))                                                                        |
| Mover para outro mês                       | `PATCH { period, dueDate }`, `MovePeriodDialog`                 | Leva um lançamento feito uma vez para outro mês, com o vencimento junto (num Crédito, o da fatura daquele mês) e as partes pendentes de uma divisão; não vale para mês de recorrência, parcela nem parte ([ADR 0029](../adr/0029-lancamentos-e-integridade-no-banco.md)) |
| Onde / Meio                                | coluna `merchant` da tabela de Lançamentos                      | O estabelecimento e, embaixo, o meio de pagamento, numa coluna só da tabela                                                                                                                                                                                              |
| Ver como: Lista / Tabela                   | `ViewMode` (`LIST` / `TABLE`)                                   | Como uma página de linhas aparece a partir de 1280 px                                                                                                                                                                                                                    |
| Pendente / Vencido / Pago, Recebido        | `PENDING` / `OVERDUE` / `SETTLED`                               | Situação derivada (`transactionStatus`, [modelo](modelo.md#transaction-lançamento))                                                                                                                                                                                      |
| Recorrência                                | `Recurrence`                                                    | Lançamento que se repete todo mês ou todo ano                                                                                                                                                                                                                            |
| Todo mês / Todo ano                        | `intervalMonths` (1 / 12)                                       | A frequência de uma recorrência; uma anual se repete no mês em que começou                                                                                                                                                                                               |
| Recorrentes                                | seção de `RecurrencesPage`                                      | As recorrências mensais e anuais, em Recorrências (antes "Todo mês")                                                                                                                                                                                                     |
| Valor estimado                             | `amountEstimated`                                               | Valor de uma recorrência variável ainda não confirmado                                                                                                                                                                                                                   |
| Parcelamento / Parcela                     | `InstallmentPlan` / `installment`                               | Compra ou dívida dividida em parcelas, uma por mês                                                                                                                                                                                                                       |
| Pessoa                                     | `Person`                                                        | Contato do espaço a quem se deve ou que deve                                                                                                                                                                                                                             |
| Membro / Você (selos de Pessoa)            | `isMember`, `memberUserId`                                      | A pessoa de um membro do espaço compartilhado, criada sozinha; "Você" é a sua                                                                                                                                                                                            |
| A receber de / A pagar para                | `personId`                                                      | A pessoa ligada a uma entrada ou saída, recorrência ou parcelamento                                                                                                                                                                                                      |
| Dividir com alguém                         | `split`, `splitOfId`                                            | Cria uma parte pendente por pessoa, no lado oposto ao lançamento                                                                                                                                                                                                         |
| Reembolso                                  | `REIMBURSEMENT_CATEGORY_NAME`                                   | A categoria de entrada das partes de uma saída dividida                                                                                                                                                                                                                  |
| Repasse                                    | `PASS_THROUGH_CATEGORY_NAME`                                    | A categoria de saída das partes de uma entrada dividida ([ADR 0052](../adr/0052-divisao-em-entradas-recorrencias-e-parcelamentos.md))                                                                                                                                    |
| Divisão (selo)                             | `splitRole`                                                     | Marca Reembolso e Repasse em Categorias: recebem as partes das divisões e não mudam (nota no [ADR 0052](../adr/0052-divisao-em-entradas-recorrencias-e-parcelamentos.md))                                                                                                |
| Nem renda nem gasto (selo)                 | `neutral`                                                       | Marca uma categoria de empréstimos e devoluções: conta no saldo (e a saída, na sobra para guardar), mas não nas entradas do mês, no limite de gastos nem nos gastos da Análise ([ADR 0056](../adr/0056-categoria-nem-renda-nem-gasto.md))                                |
| Categoria da devolução / Devolução em …    | `returnCategoryId`                                              | Numa categoria de saída "Nem renda nem gasto", a categoria de entrada marcada que recebe o valor a receber de um empréstimo ([ADR 0058](../adr/0058-emprestado-para.md))                                                                                                 |
| Emprestado para                            | `split` numa saída cuja categoria tem `returnCategoryId`        | "Dividir com alguém" numa saída de empréstimo: o valor começa inteiro com a pessoa, e a parte vai para a categoria da volta (ADR 0058)                                                                                                                                   |
| Categoria da dívida / Dívida em …          | `returnCategoryId` numa categoria de entrada                    | Numa categoria de entrada "Nem renda nem gasto", a categoria de saída marcada que guarda o valor a pagar de um empréstimo tomado ([ADR 0059](../adr/0059-peguei-emprestado-de.md))                                                                                       |
| Peguei emprestado de / De quem?            | `split` numa entrada cuja categoria tem `returnCategoryId`      | "Dividir com alguém" numa entrada de empréstimo: o valor começa inteiro com a pessoa, e a parte a pagar vai para a categoria da dívida (ADR 0059)                                                                                                                        |
| Extrato do banco / Planilha modelo         | `/importar/extrato`, `/importar/planilha`, `imports.kind`       | As duas páginas de "Importar": os extratos de um banco (fatura do cartão e, depois, conta) e a planilha do app; cada importação guarda o tipo e o banco ([ADR 0060](../adr/0060-extratos-do-banco.md))                                                                   |
| Desfazer importação / Remover do histórico | `DELETE …/imports/:id` (`?keepTransactions=true`), `dependents` | Desfazer apaga os lançamentos e parcelamentos da importação, e a confirmação diz o que mais muda; remover do histórico só tira a importação da lista, e os lançamentos ficam (nota no ADR 0060)                                                                          |
| Identificador do movimento                 | `externalId` (`transactions.external_id`)                       | O código que o banco dá a cada movimento da conta, guardado com o banco ("NUBANK:<código>"): um extrato importado de novo sabe o que já veio ([ADR 0061](../adr/0061-extrato-da-conta-e-conferencia.md))                                                                 |
| Conferência / Já lançado / Quitar pendente | `matches` na importação, `POST …/imports/candidates`            | Casar cada movimento do extrato com o que já está no app: o lançamento recebe o identificador e, se pendente, é quitado no dia do movimento, em vez de virar um novo (ADR 0061)                                                                                          |
| Com quem?                                  | `PeopleMultiSelect`, `split`                                    | Na divisão, escolhe várias pessoas de uma vez; cada uma ganha a sua linha                                                                                                                                                                                                |
| Adicionar 'Nome'                           | `PersonSelect`, `MerchantSelect`, `CategorySelect` (`allowAdd`) | Nos seletores de pessoa, estabelecimento e categoria, cadastra o que ainda não está na lista, ao salvar; um arquivado de mesmo nome volta                                                                                                                                |
| Estabelecimento                            | `Merchant`, `merchantId`                                        | Onde se comprou ou quem pagou (Mercado A, Netflix, Empresa X), em saídas e entradas ([ADR 0053](../adr/0053-estabelecimentos.md))                                                                                                                                        |
| Apelido (do estabelecimento)               | `MerchantAlias`                                                 | Um texto como o estabelecimento aparece no extrato ("Ifd*Paladar Pizzas"), ligado ao estabelecimento cadastrado ([ADR 0055](../adr/0055-importacao-da-fatura-do-cartao.md))                                                                                              |
| Fatura do cartão                           | origem da importação                                            | O arquivo da fatura exportado pelo banco (o CSV do Nubank, primeiro), lido como a planilha modelo ([ADR 0055](../adr/0055-importacao-da-fatura-do-cartao.md))                                                                                                            |
| Cartão                                     | `Card`, `cardId`                                                | Um cartão do espaço ("Nubank"), com o banco e as funções; um detalhe dos meios Crédito e Débito, sem limite nem saldo ([ADR 0062](../adr/0062-cartoes-e-pagar-fatura.md))                                                                                                |
| Funções (Crédito / Débito)                 | `functions` (`CREDIT`, `DEBIT`)                                 | O que o cartão faz; um cartão múltiplo tem as duas. Só com Crédito ele tem o dia do fechamento e o do vencimento ([ADR 0062](../adr/0062-cartoes-e-pagar-fatura.md))                                                                                                     |
| Fatura                                     | `bill` (o cartão mais o vencimento)                             | Os lançamentos de um cartão no Crédito que vencem no mesmo dia; não é uma tabela ([ADR 0062](../adr/0062-cartoes-e-pagar-fatura.md))                                                                                                                                     |
| Pagar fatura                               | `payBill`                                                       | Quita numa vez os pendentes de uma fatura, compras e estornos, num só dia, com "Desfazer" ([ADR 0062](../adr/0062-cartoes-e-pagar-fatura.md))                                                                                                                            |
| Parcela inicial                            | `firstNumber`                                                   | Em que parcela um parcelamento começa no app ("Parcela 3/10"), para um já em andamento ([ADR 0055](../adr/0055-importacao-da-fatura-do-cartao.md))                                                                                                                       |
| Meio de pagamento / Meio de recebimento    | `PaymentMethod`, `paymentMethod`                                | Como se pagou (saída) ou recebeu (entrada): Pix, Débito, Crédito, Vale-alimentação/refeição, Dinheiro, Boleto, Transferência ou Débito automático ([ADR 0054](../adr/0054-meio-de-pagamento.md))                                                                         |
| Sugerida pelo histórico                    | `suggestCategory`, `GET …/categories/hints`                     | Categoria preenchida num lançamento novo pela mais usada com o estabelecimento ou a descrição nos últimos 12 meses ([ADR 0053](../adr/0053-estabelecimentos.md))                                                                                                         |
| Importação                                 | `TransactionImport`                                             | Lançamentos trazidos de uma planilha, desfazível                                                                                                                                                                                                                         |

### Orçamento e Painel

| Interface                                                   | Código                                           | Definição                                                                                                                                                                     |
| ----------------------------------------------------------- | ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Orçamento do mês                                            | `BudgetConfig` + `BudgetShare`                   | A renda líquida e os percentuais salvos para um mês, herdados pelos seguintes                                                                                                 |
| Renda líquida                                               | `netIncomeCents`                                 | A base do limite de gastos                                                                                                                                                    |
| Limite de gastos                                            | destino `EXPENSES`                               | O % da renda líquida que se planeja gastar                                                                                                                                    |
| Gastos                                                      | `expenses`                                       | Saídas fora das categorias das metas de guardar, pagas ou não; por isso diferem das saídas                                                                                    |
| Entradas do mês (no orçamento)                              | `incomeCents`                                    | As entradas da competência, recebidas ou a receber, sem as partes das divisões (Reembolso); comparadas com a renda líquida no Painel                                          |
| Sobra para guardar                                          | `available`                                      | Entradas − despesas: a base das metas de guardar                                                                                                                              |
| Meta                                                        | `BudgetDestination` `SAVINGS`                    | Um % da sobra para guardar, com a sua categoria de saída (Reserva de emergência…)                                                                                             |
| Guardar / Guardado (formulário: "Registrar valor guardado") | saída na categoria da meta, `appliedCents`       | Registrar dinheiro guardado numa meta (descrição preenchida "Aporte em {meta}") / o total já pago nela                                                                        |
| Pendente (na meta)                                          | `pendingCents`                                   | Saídas da meta ainda não pagas                                                                                                                                                |
| Progresso                                                   | `appliedCents ÷ targetCents`                     | Quanto da meta já foi guardado, em %                                                                                                                                          |
| Falta lançar                                                | `targetCents − appliedCents − pendingCents`      | O que da meta ainda não foi lançado, nem pago nem pendente                                                                                                                    |
| Para guardar                                                | `applied.plannedCents` (Análise, visão prevista) | O que vai para as metas, pago ou não                                                                                                                                          |
| Sem meta                                                    | `unallocated`                                    | A parte da sobra prevista que nenhuma meta recebeu; uma divisão do orçamento, não um saldo                                                                                    |
| Previsto / Realizado                                        | visões `planned` / `settled`                     | Tudo o que foi lançado / só o que já foi pago ou recebido                                                                                                                     |
| Saldo previsto                                              | `balance.plannedCents`                           | Como o mês termina se tudo for pago e recebido                                                                                                                                |
| A receber sem vencimento                                    | `undatedCents`, `undatedReceivable`              | Entrada pendente sem vencimento numa categoria "Nem renda nem gasto": fica nas Entradas, mas fora do Saldo previsto (ADR 0057)                                                |
| A pagar sem vencimento                                      | `undatedPayableCents`, `undatedPayable`          | Saída pendente sem vencimento numa categoria "Nem renda nem gasto" (uma dívida sem prazo): fica nas Saídas, mas fora do Saldo previsto e da sobra prevista (nota no ADR 0057) |
| Saldo atual                                                 | `balance.settledCents`                           | Recebido − pago até agora                                                                                                                                                     |

### Fechamento do mês

| Interface               | Código                                                     | Definição                                                                                                                                                              |
| ----------------------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Fechar mês              | `closePeriod`, `POST …/periods/:period/close`              | Trava a competência depois de tudo pago e recebido; só fecha sem pendências, fora o a receber ou a pagar sem vencimento ([ADR 0063](../adr/0063-fechamento-do-mes.md)) |
| Mês fechado             | `PeriodClosing` (`period_closings`), `closed`              | A competência com um fechamento em vigor: nada nela muda (`PERIOD_CLOSED`)                                                                                             |
| Reabrir mês             | `reopenPeriod`, `POST …/periods/:period/reopen { reason }` | Destrava a competência para uma correção, com o motivo guardado no histórico                                                                                           |
| O que falta para fechar | `PERIOD_HAS_PENDING`                                       | Os lançamentos pendentes que impedem o fechamento                                                                                                                      |

| Dicionário SX2/SX3, UPDDISTR             | `schema.prisma` e migrações Prisma                                                                                                                           |

| Serviços REST (WSRESTFUL)                | Controllers REST do NestJS                                                                                                                                   |
| Pontos de entrada                        | Eventos/hooks da aplicação                                                                                                                                   |
| Consulta padrão (SXB)                    | Endpoints de listagem/busca + componentes de seleção                                                                                                         |
| Job / schedule                           | GitHub Actions agendado ou cron do provedor                                                                                                                  |
| `MV_DATAFIN` (data limite do Financeiro) | Fechamento do mês, mas por competência e não por uma data limite: reabrir março não reabre os meses seguintes ([ADR 0063](../adr/0063-fechamento-do-mes.md)) |
